# Dziennik

**World of Warcraft: Forever** addon (1.60.x, interface 16001) by **Ob-Went**.

🇵🇱 Dziennik podróżnika: pierwsza wizyta w każdej strefie (ze zrzutem ekranu), nowe poziomy, śmierci. Z addonami Odkrywca, Rybak i Kupiec zapisuje też pierwsze zebrane zasoby, ryby i poznanych kupców.

🇬🇧 Traveler's journal: first visit to every zone (with a screenshot), level-ups, deaths. With Odkrywca, Rybak and Kupiec it also records first resources, fish and vendors.

## Features / Funkcje

- Journal window (`/dziennik`), newest first
- Screenshot on your first visit to a zone (optional)
- Public API for other addons: `Dziennik_Add(kind, name, zone)`
- Polish and English

## Installation / Instalacja

Copy the `Dziennik` folder to `World of Warcraft\_forever_\Interface\AddOns\`.

## Commands / Komendy

| PL | EN | |
|---|---|---|
| `/dziennik` | `/journal` | open/close the journal |
| `/dziennik zdjecia` | `/dziennik screenshots` | screenshots of new zones |
| `/dziennik ogloszenia` | `/dziennik announce` | new entries in chat too |
| `/dziennik wyczysc tak` | `/dziennik clear yes` | clear this character's journal |
| `/dziennik jezyk en` | `/dziennik lang pl` | language |
